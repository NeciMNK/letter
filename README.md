# letter

Открытый текстовый редактор для Windows, macOS и Linux, написанный на Rust.
Цель — повторить внешний вид, возможности и совместимость с файлами
Microsoft Word (2024 и более ранних версий).

Проект в работе: многое уже есть, но до полной замены Word ещё далеко.
План работ и что сделано — в [plan.md](plan.md).

## Что уже умеет

**Файлы.**

- **.docx** — открытие и сохранение без потерь: то, что программа пока не
  понимает, сохраняется как было. Также шаблоны и документы с макросами
  (.dotx, .docm, .dotm; макросы сохраняются, но не выполняются) и .docx
  с паролем на открытие.
- **.doc и .dot** (Word 97–2003) — открытие и сохранение в .doc: текст,
  стили, таблицы, списки, разделы, колонтитулы, сноски, примечания,
  картинки, фигуры и надписи, гиперссылки и закладки. Открываются и .doc
  с паролем, и файлы старых Word 6.0/95.
- **RTF, ODT** (LibreOffice) — открытие и сохранение.
- **TXT, HTML, Markdown** — открытие и сохранение.
- **PDF** — сохранение со встроенными шрифтами, ссылками и закладками
  по заголовкам. Печать через системное окно печати.

**Документ.** Шрифты и оформление абзацев, стили, списки, таблицы,
картинки и обтекание, разделы и колонки, колонтитулы, номера страниц,
поля, гиперссылки и закладки, сноски, оглавление, границы и заливка,
специальные символы, автоматические переносы.

**Сложные объекты.** Формулы (показ и сохранение без потерь), диаграммы
(гистограмма, график, круговая и другие — по данным из документа),
SmartArt, фигуры и надписи — их можно открыть, посмотреть и сохранить,
но пока нельзя вставить новые: редакторов формул и фигур ещё нет.
Элементы управления содержимым (поля для текста, флажки, списки, дата)
можно заполнять.

**Рецензирование.** Примечания с ответами, исправления (запись,
принять/отклонить), сравнение двух документов, статистика, защита
документа. Проверка орфографии подчёркивает ошибки и предлагает замены.

**Интерфейс** в стиле Word: лента одной высоты на всех вкладках («Файл»,
«Главная», «Вставка», «Конструктор», «Макет», «Ссылки», «Рецензирование»,
«Вид»), панель быстрого доступа, линейка, строка состояния, режимы
просмотра, масштаб, контекстное меню, горячие клавиши и подсказки клавиш
по Alt, светлая и тёмная темы, русский и английский языки.

### Словари для проверки орфографии

Словари в программу не встроены — она берёт словари формата Hunspell
(файлы `.aff` и `.dic`), которые уже есть на компьютере:

- **Linux:** системные (`/usr/share/hunspell`, пакеты `hunspell-ru`,
  `hunspell-en-us`) и словари LibreOffice;
- **macOS:** `/Library/Spelling`, `~/Library/Spelling` и словари LibreOffice;
- **Windows:** словари установленного LibreOffice.

Можно также положить файлы словаря в папку `dictionaries` в папке настроек
программы (у портативной версии — в `letter-data/dictionaries`).

## Скачать готовую программу

Готовые сборки лежат на странице
[Releases](https://github.com/bikhe/letter/releases): выпуски с номером
версии и «Ночная сборка» — самая свежая, из ветки main (обновляется после
каждого изменения в main).

- **Windows:** `.msi` или `-setup.exe` — установщик; `-windows-x64-portable.zip` —
  портативная версия: распакуйте куда угодно и запустите `letter.exe`.
- **macOS:** `.dmg` — установка; `-macos-portable.zip` — `letter.app` без установки.
- **Linux:** `.deb` — пакет для Ubuntu/Debian; `.AppImage` и
  `-linux-x64-portable.tar.gz` — запуск без установки.

Портативная версия хранит настройки в папке `letter-data` рядом с программой.
Сборки пока не подписаны, поэтому Windows и macOS при первом запуске
предупредят о неизвестном издателе.

## Как собрать и запустить

Понадобится около 2 ГБ свободного места и интернет (первая сборка скачивает
библиотеки).

### 1. Установите Rust

- **Windows:** скачайте и запустите `rustup-init.exe` с сайта
  <https://rustup.rs>. Если установщик попросит поставить
  «Visual Studio C++ Build Tools», согласитесь (нужен вариант
  «Desktop development with C++»).
- **macOS:** откройте «Терминал» и выполните:
  ```sh
  xcode-select --install
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Linux:** в терминале выполните:
  ```sh
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
  Для Ubuntu/Debian также нужны пакеты:
  ```sh
  sudo apt install build-essential pkg-config libxkbcommon-x11-0 \
    libxkbcommon-dev libwayland-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev
  ```

После установки закройте терминал и откройте его заново.

### 2. Скачайте проект

Нажмите на GitHub зелёную кнопку **Code → Download ZIP** и распакуйте архив,
или, если установлен git:

```sh
git clone https://github.com/bikhe/letter.git
cd letter
```

### 3. Запустите

В терминале, находясь в папке проекта:

```sh
cargo run -p letter-app
```

Первая сборка занимает несколько минут, следующие — секунды. Должно открыться
окно редактора с пустым документом.

## Для разработчиков

Перед отправкой изменений должны проходить:

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

То же самое проверяет CI на Windows, macOS и Linux. Правила работы и
архитектура описаны в [plan.md](plan.md).

Выпуск новой версии: поставить метку `vX.Y.Z` и отправить её
(`git tag v0.1.0 && git push --tags`). CI сам соберёт установщики и
портативные версии для всех трёх систем и выложит их на страницу Releases.
Метка с дефисом (например, `v0.2.0-beta`) — предварительный выпуск.

Консольная утилита `letter-cli` для отладки (работает с .docx): показать,
как программа поняла файл, проверить сохранение, разложить по страницам,
нарисовать страницы в PNG, сохранить в PDF, сверить вёрстку с PDF из Word,
сравнить два документа:

```sh
cargo run -p letter-cli -- dump документ.docx
cargo run -p letter-cli -- roundtrip документ.docx копия.docx
cargo run -p letter-cli -- pages документ.docx
cargo run -p letter-cli -- render документ.docx папка
cargo run -p letter-cli -- pdf документ.docx документ.pdf
cargo run -p letter-cli -- compare документ.docx эталон-из-word.pdf
cargo run -p letter-cli -- pdf-lines эталон-из-word.pdf
cargo run -p letter-cli -- diff исходный.docx изменённый.docx итог.docx
```

Сверка вёрстки с Word по всем эталонам — `cargo test -p letter-cli --test
compare -- --nocapture` (подробнее в
[tests/fixtures/reference/README.md](tests/fixtures/reference/README.md)).
