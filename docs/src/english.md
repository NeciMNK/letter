# English

**letter** is a free word processor for Windows, macOS and Linux that looks
and works like Microsoft Word and opens and saves Word documents (.docx and
the older .doc) without losing anything. It works fully offline.

- **Download:** installers and portable builds are on the
  [Releases](https://github.com/bikhe/letter/releases) page (.msi, setup.exe
  and .msix for Windows; .dmg for macOS; .deb, .AppImage and .flatpak for
  Linux).
- **Interface language:** English or Russian — **File → Options →
  Interface language**.
- **Formats:** .docx, .docm, .dotx, .dotm, .doc, .dot, .rtf, .odt, .html,
  .md, .txt; export to PDF; printing.
- **Keyboard:** the same shortcuts as Word (see the
  [shortcut table](shortcuts.md); key names there are universal). Press Alt
  for KeyTips, F6 to move between the document, panes, status bar and
  ribbon.
- **Accessibility:** works with NVDA, Narrator, VoiceOver and Orca.

The user guide is written in Russian for now. The source code and the issue
tracker are at <https://github.com/bikhe/letter>.
