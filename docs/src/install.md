# Установка

Готовые сборки лежат на странице
[Releases](https://github.com/bikhe/letter/releases). Там есть выпуски с номером
версии и «Ночная сборка». Ночная сборка самая свежая: она обновляется после
каждого изменения программы, но может быть менее стабильной.

## Windows

- Файл **`.msi`** или **`…-setup.exe`** — обычный
  установщик. Скачайте, запустите и следуйте шагам.
- Файл **`.msix`** — пакет для «Установщика приложений» Windows
  (ставится, только если сборка подписана).
- **`…-windows-x64-portable.zip`** — портативная версия без установки:
  распакуйте архив в любую папку (хоть на флешку) и запустите `letter.exe`.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите
«Подробнее» → «Выполнить в любом случае». Так бывает с программами без
цифровой подписи издателя.

## macOS

- Файл **`.dmg`** — откройте образ и перетащите letter в папку
  «Программы».
- **`…-macos-portable.zip`** — `letter.app` без установки.

Если macOS сообщит, что не может проверить разработчика, откройте программу
через контекстное меню: щёлкните по ней правой кнопкой → «Открыть» →
«Открыть».

## Linux

- **`.deb`** — для Ubuntu, Debian и похожих систем:
  `sudo apt install ./имя-файла.deb`.
- **`.AppImage`** — запуск без установки: сделайте файл исполняемым
  (`chmod +x имя-файла.AppImage`) и запустите.
- **`.flatpak`** — для любой системы с Flatpak:
  `flatpak install имя-файла.flatpak`.
- **`-linux-x64-portable.tar.gz`** — портативная версия: распакуйте и
  запустите `letter`.

## Портативная версия

Портативная версия хранит свои настройки, словари и шаблоны в папке
`letter-data` рядом с программой, а не в папке пользователя. Её можно носить
на флешке вместе со всеми настройками.
