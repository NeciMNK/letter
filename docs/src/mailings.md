# Рассылки, наклейки и конверты

Рассылка (слияние) делает из одного документа много: например, одно и то же
письмо для каждого человека из списка, с его именем и адресом. Всё это — на
вкладке **«Рассылки»**.

## 1. Список получателей

Подготовьте таблицу получателей. Подойдёт:

- файл **CSV** (его сохраняет любая программа таблиц: «Сохранить как → CSV»):
  в первой строке названия столбцов, например `Имя;Фамилия;Город`, ниже —
  по строке на человека. Кодировка UTF-8 или Windows-1251;
- или документ (.docx и другие), в котором есть таблица с названиями
  столбцов в первой строке.

Нажмите **«Выбрать получателей»** и укажите файл. **«Изменить список
получателей»** позволяет снять отметку с тех, кому писать не нужно,
отсортировать и отфильтровать список. Список и отметки сохраняются в
документе: после повторного открытия он подключится снова.

## 2. Поля

Поставьте курсор в нужное место текста и вставьте поле:

- **«Вставить поле слияния»** — значение столбца (например, «Имя»);
- **«Блок адреса»** — имя, организация, адрес, индекс и город из столбцов с
  такими названиями;
- **«Строка приветствия»** — «Уважаемый(ая) Иван Петрович!»;
- **«Правила»** — текст по условию («если Город = Москва, то …»), номер
  записи, пропуск записи.

## 3. Просмотр

**«Просмотр результатов»** показывает вместо названий полей данные
получателя; стрелки переключают получателей.

## 4. Завершение

**«Найти и объединить»**:

- **«Изменить отдельные документы…»** — новый документ, в котором для каждого
  получателя своя копия, каждая с новой страницы. Его можно поправить,
  напечатать или сохранить;
- **«Сохранить в PDF…»** — сразу файл PDF со всеми письмами.

## Наклейки

**«Наклейки»** превращают документ в лист наклеек (размеры распространённых
листов Avery, A4 и Letter). Оформите первую наклейку (например, вставьте
«Блок адреса») и нажмите **«Обновить наклейки»** — она повторится на всех
остальных. При слиянии каждая наклейка получит следующего получателя.

## Конверты

**«Конверты»** открывают окно: адрес получателя (или «Блок адреса
рассылки» — тогда при слиянии свой конверт для каждого получателя),
обратный адрес и размер конверта (DL, C6, C5, C4, № 10). **«Добавить в
документ»** ставит конверт первой страницей документа.
