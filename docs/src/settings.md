# Параметры и файлы программы

## Параметры

**Файл → Параметры**:

- **Автосохранение каждые … мин** — как часто сохранять копию открытых
  документов на случай сбоя (по умолчанию 2 минуты).
- **Показывать линейку при запуске**.
- **Тема оформления** — светлая, тёмная или как в системе.
- **Язык интерфейса** — русский или английский.

## Где программа хранит свои файлы

Настройки, список недавних файлов, автосохранения, личные шаблоны и словари
лежат в папке программы:

| Система | Папка |
|---|---|
| Windows | `%APPDATA%\letter` |
| macOS | `~/Library/Application Support/letter` |
| Linux | `~/.config/letter` (или `$XDG_CONFIG_HOME/letter`) |
| Портативная версия | `letter-data` рядом с программой |

В этой папке:

- `settings.txt` — параметры;
- `autosave` — копии несохранённых документов для восстановления после сбоя;
- `templates` — [личные шаблоны](templates.md);
- `dictionaries` — свои словари для проверки орфографии.

## Словари

Словари для проверки орфографии в программу не встроены: она берёт словари
формата Hunspell (пары файлов `.aff` и `.dic`), которые уже есть на
компьютере.

- **Linux:** системные словари (`/usr/share/hunspell`; пакеты
  `hunspell-ru`, `hunspell-en-us`) и словари LibreOffice.
- **macOS:** `/Library/Spelling`, `~/Library/Spelling` и словари LibreOffice.
- **Windows:** словари установленного LibreOffice.

Ещё можно положить файлы словаря (например, `ru_RU.aff` и `ru_RU.dic`) в
папку `dictionaries` в папке программы. Язык текста программа берёт из
документа и показывает в строке состояния.

## Восстановление после сбоя

Если программа закрылась неожиданно, при следующем запуске появится окно
«Восстановление документов» со списком несохранённых документов. Откройте
нужные и сохраните их.
