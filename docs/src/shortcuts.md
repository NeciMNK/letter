# Сочетания клавиш

Сочетания такие же, как в Word. На Mac вместо Ctrl нажимайте ⌘ (Cmd).
При русской раскладке буквы работают по месту клавиши: Ctrl+И — то же,
что Ctrl+B.

Кроме сочетаний, можно нажать **Alt**: над вкладками и кнопками ленты
появятся буквы-подсказки, и любую команду можно выбрать с клавиатуры
(например, Alt, Я, 1 — полужирный).

## Файлы

| Клавиши | Действие |
|---|---|
| `Ctrl+N` | Новый документ |
| `Ctrl+O` | Открыть |
| `Ctrl+S` | Сохранить |
| `F12` | Сохранить как |
| `Ctrl+P` или `Ctrl+F2` | Печать и предварительный просмотр |
| `Ctrl+W` или `Ctrl+F4` | Закрыть документ |
| `Alt+F4` | Выйти из программы |

## Правка

| Клавиши | Действие |
|---|---|
| `Ctrl+Z` или `Alt+Backspace` | Отменить |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Вернуть |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Вырезать, копировать, вставить |
| `Ctrl+A` | Выделить всё |
| `Ctrl+F` | Найти |
| `Ctrl+H` | Найти и заменить |
| `Ctrl+K` | Ссылка |
| `Ctrl+Backspace` | Удалить слово слева |
| `Ctrl+Delete` | Удалить слово справа |
| `Ctrl+Shift+Пробел` | Неразрывный пробел |
| `Ctrl+Shift+-` | Неразрывный дефис |
| `Ctrl+-` | Мягкий перенос |
| `Ctrl+Shift+8` | Отобразить все знаки |
| `Ctrl+Shift+E` | Запись исправлений |
| `Ctrl+Alt+M` | Создать примечание |
| `F7` | Следующая ошибка правописания |
| `F9` | Обновить поля |
| `Ctrl+Alt+F` | Вставить сноску |
| `Ctrl+Alt+D` | Вставить концевую сноску |

## Шрифт

| Клавиши | Действие |
|---|---|
| `Ctrl+D` | Окно «Шрифт» |
| `Ctrl+B` | Полужирный |
| `Ctrl+I` | Курсив |
| `Ctrl+U` | Подчёркнутый |
| `Ctrl+Shift+D` | Двойное подчёркивание |
| `Ctrl+Shift+W` | Подчёркивание только слов |
| `Ctrl+Shift+A` | Все прописные |
| `Ctrl+Shift+K` | Малые прописные |
| `Ctrl+Shift+H` | Скрытый текст |
| `Ctrl+=` | Подстрочный знак |
| `Ctrl+Shift+=` | Надстрочный знак |
| `Ctrl+]` | Увеличить размер на 1 пт |
| `Ctrl+[` | Уменьшить размер на 1 пт |
| `Ctrl+Shift+.` | Увеличить размер шрифта (следующий из списка) |
| `Ctrl+Shift+,` | Уменьшить размер шрифта (предыдущий из списка) |
| `Ctrl+Пробел` | Очистить оформление знаков |

## Абзац и стили

| Клавиши | Действие |
|---|---|
| `Ctrl+L` | По левому краю |
| `Ctrl+E` | По центру |
| `Ctrl+R` | По правому краю |
| `Ctrl+J` | По ширине |
| `Ctrl+M` | Увеличить отступ |
| `Ctrl+Shift+M` | Уменьшить отступ |
| `Ctrl+T` | Увеличить выступ |
| `Ctrl+Shift+T` | Уменьшить выступ |
| `Ctrl+1` | Одинарный интервал |
| `Ctrl+2` | Двойной интервал |
| `Ctrl+5` | Полуторный интервал |
| `Ctrl+0` | Добавить или убрать интервал перед абзацем |
| `Ctrl+Q` | Убрать оформление абзаца |
| `Ctrl+Shift+N` | Стиль «Обычный» |
| `Ctrl+Alt+1`, `Ctrl+Alt+2`, `Ctrl+Alt+3` | Заголовок 1, 2, 3 |

## Режимы и структура

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+P` | Разметка страницы |
| `Ctrl+Alt+O` | Структура |
| `Ctrl+Alt+N` | Черновик |
| `Alt+Shift+←` | Повысить уровень заголовка |
| `Alt+Shift+→` | Понизить уровень заголовка |
| `Alt+Shift+=` или `Alt+Shift++` | Развернуть заголовок (в режиме «Структура») |
| `Alt+Shift+-` | Свернуть заголовок |

## Курсор и выделение

| Клавиши | Действие |
|---|---|
| `←` `→` `↑` `↓` | На знак или строку |
| `Ctrl+←`, `Ctrl+→` | На слово |
| `Ctrl+↑`, `Ctrl+↓` | На абзац |
| `Home`, `End` | В начало или конец строки |
| `Ctrl+Home`, `Ctrl+End` | В начало или конец документа |
| `PageUp`, `PageDown` | На экран вверх или вниз |
| `Shift` + любое из перечисленного | Выделить |
| `Enter` | Новый абзац |
| `Shift+Enter` | Новая строка в том же абзаце |
| `Ctrl+Enter` | Разрыв страницы |
| `Ctrl+Shift+Enter` | Разрыв колонки |
| `Tab`, `Shift+Tab` | Табуляция; в списке — уровень пункта; в таблице — соседняя ячейка |
| Ctrl+щелчок по ссылке | Открыть ссылку |
| Ctrl+колёсико мыши | Масштаб |

## Окно

| Клавиши | Действие |
|---|---|
| `Alt` | Подсказки клавиш на ленте |
| `F6`, `Shift+F6` | Перейти к следующей или предыдущей части окна |
| `Esc` | Вернуться в документ, закрыть окно, колонтитул или режим чтения |
