# Шаблоны

Шаблон — заготовка документа: оформление и текст, который остаётся
дополнить.

## Встроенные шаблоны

В **Файл → Создать** кроме пустого документа есть шаблоны: деловое письмо,
резюме, отчёт, служебная записка, заявление. Щелчок по шаблону открывает
новый документ по нему; вписывайте свои данные вместо текста в
квадратных скобках.

## Свои шаблоны

1. Оформите документ, как нужно, и сохраните его как **«Шаблон Word
   (.dotx)»** (F12, выбрать тип файла).
2. В **Файл → Создать** нажмите **«Добавить шаблон…»** и выберите этот
   файл.

Шаблон появится в разделе «Личные». Документ по шаблону открывается без
имени, поэтому сам шаблон случайно не перезапишется. Подойдут и шаблоны из
Word (.dotx, .dotm, .dot).

Личные шаблоны лежат в папке `templates` в папке настроек программы (см.
[«Параметры и файлы программы»](settings.md)).
