letter — портативная версия
============================

Установка не нужна: распакуйте архив куда угодно (например, на флешку)
и запустите letter (в Windows — letter.exe).

Настройки, список последних файлов и автосохранения хранятся в папке
letter-data рядом с программой, а не в профиле пользователя. Если удалить
эту папку, программа будет хранить их как обычная установленная версия.

Сайт проекта: https://github.com/bikhe/letter

---

letter — portable version

No installation needed: unpack the archive anywhere (for example, to a USB
drive) and run letter (letter.exe on Windows). Settings, recent files and
autosaves are kept in the letter-data folder next to the program.
